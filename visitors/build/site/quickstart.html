Quick start

Everything is on the device; this is the map. Unit A only.

FX / SEL / ENV / LFOOtter / Cat / Fox / Hopper: that track on the keys; again: next page; hold + K1/K2: level / pan
SEQthe Beaver (patterns, steps, song)
EDITthe mixer: levels, pans, FX, MASTER; keys 1-4 mute, 9-12 solo, 5-8 & 13-16 scenes
HOMEthe home screen: five tiles, keys 1-6 jump, key 7 = NEW BEAT
PLAYrun / stop
RECstopped: step entry on the focused track (OCT+ rest, OCT- back); playing: arm it for live record; hold 1 s: clear it
GLOtap tempo
ARPHopper: sample the output until ARP again; it lands chopped
SAVEkeep everything
PRESET knobpage
ALGO knobpreset / kit / 808 & bass / sample source / pattern
SELECT knobtrack
K1-K4always the four things on the screen
Beaver white keystoggle the focused track's steps; hold one + K1-K4 = NOTE VEL LENGTH PROB, + GEN = ratchet x1-x4
Beaver black keysCOPY PASTE CLR CHAIN BEAT M1 M2 M3 M4 GEN SOLO (CHAIN held + keys 1-8 writes the song, + CLR clears it)

Flashing

In the Claude session's workflow: wsl -d Ubuntu -e bash -lc "cd ~/sfa-fm1 && git pull && tools/go.sh" with the FM-1 alone on USB. From this site: Install works in Chrome or Edge over Web MIDI. Your own samples: python3 tools/sfa_sample.py mydir/, then flash.
